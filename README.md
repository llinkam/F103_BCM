# STM32F103 车身控制器（BCM）

> 基于 STM32F103 + FreeRTOS 的车身控制器项目：在工控板上完成开关量输入采集与继电器/MOS 输出驱动，后续逐步加入灯光与门锁逻辑、CAN/LIN 通信、故障诊断和 UDS 刷写。

**状态：开发中**。数字输入、输出驱动已完成，KEY1 控制继电器 K1 已上板验证；应用层逻辑和通信部分还没开始。

## 项目背景

车身控制器（BCM）负责灯光、门锁、雨刮等车身电器。它的核心工作方式是**周期性地"读输入 → 做判断 → 写输出"**，同时通过 CAN、LIN 与其他 ECU 通信。

本项目在一块现成的 STM32F103 工控板上实现这条链路，不涉及硬件焊接，重点放在软件分层和代码结构上。

最终计划与 [STM32-UDS-Bootloader](https://github.com/llinkam/STM32-UDS-Bootloader) 衔接，通过 UDS 刷写本工程的固件。

## 硬件平台

| 项目 | 说明 |
|---|---|
| 主控 | STM32F103C8T6，Cortex-M3，72MHz，Flash 64KB，RAM 20KB |
| 时钟 | 外部 8MHz 晶振，PLL 9 倍频到 72MHz；32.768kHz RTC 晶振 |
| 数字输入 | 8 路 PC817 光耦隔离输入，板载按键 KEY1、KEY2 |
| 继电器输出 | 4 路，SS8050 驱动，带续流二极管 |
| MOS 输出 | 4 路 2SK3615，可用于 PWM |
| CAN | TJA1050 |
| LIN | TJA1020 |
| RS485 | SP3485 |
| 模拟输入 | 4 路 ADC |
| 供电 | 12V 输入，板载降压到 5V 和 3.3V |
| 调试 | ST-Link V2，SWD |
